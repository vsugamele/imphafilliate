# Sitemap comercial para linfaflow.vip

## Navegacao principal

- `/` - Review comercial principal
- `/linfaflow-review/` - Versao SEO dedicada para "LinfaFlow review"
- `/linfaflow-funciona/` - Consideracao: beneficios, limites e expectativas realistas
- `/ingredientes/` - Ingredientes e papel de cada botanico
- `/onde-comprar/` - Compra segura, checkout, garantia e cuidados contra imitacoes
- `/faq/` - Perguntas frequentes
- `/bonus/` - Bonus afiliado, caso exista
- `/disclosure/` - Relacao de afiliado
- `/privacy-policy/`
- `/terms/`
- `/contact/`
- `/references/`

## Fluxo recomendado

1. Visitante chega por busca comercial: `/linfaflow-review/`, `/linfaflow-funciona/` ou `/onde-comprar/`.
2. Pagina responde objecoes sem parecer site oficial.
3. CTA leva para `AFFILIATE_CHECKOUT_URL`.
4. Conteudo editorial externo aponta para a review com anchor natural: "analise completa do LinfaFlow", "pagina de compra segura", "review do LinfaFlow".

## URL map por intencao

| Intencao | URL | CTA principal |
|---|---|---|
| Branded/decisao | `/linfaflow-review/` | Ver preco oficial |
| Duvida/consideracao | `/linfaflow-funciona/` | Conferir detalhes da formula |
| Compra | `/onde-comprar/` | Acessar checkout seguro |
| Ingredientes | `/ingredientes/` | Ver composicao completa |
| Objecoes | `/faq/` | Tirar duvidas e comprar |

## Interlinking

- Todas as paginas comerciais apontam para `/onde-comprar/`.
- `/ingredientes/` aponta para `/linfaflow-funciona/`.
- `/linfaflow-funciona/` aponta para `/linfaflow-review/`.
- `/faq/` aponta para `/onde-comprar/` e `/disclosure/`.
- Rodape sempre inclui disclosure, termos, privacidade, contato e fontes.
