AI Browser Automator MVP

Extensao Chrome sem API para colar e enviar prompts em ChatGPT, Gemini e Flow.

Para o fluxo detalhado do projeto JP, carrosseis, HookLab e batch diario, abra GUIDE-AUTOMACAO-JP.md.

Abrir manual visual completo com estrategias, formatos, skills, angulos, hooks e operacao da fila.

Como instalar

  1. Abra chrome://extensions.
  2. Ative Modo do desenvolvedor.
  3. Clique em Carregar sem compactacao.
  4. Selecione a pasta ai-browser-automator-mvp.

Como usar

  1. Abra ChatGPT, Gemini ou Flow e faca login.
  2. Clique no icone da extensao.
  3. Use as abas Prompt, Assistente, Projeto e Fila.
  4. Se a conexao aparecer pendente, clique em Conectar.
  5. Escreva ou selecione um template.
  6. Use Colar no site para revisar antes, ou Colar e enviar para automatizar.
  7. Para fila, coloque um prompt por linha, escolha se deve enviar automaticamente e use iniciar/pausar/parar.

Assistente com OpenRouter

  1. Crie uma chave em https://openrouter.ai/keys.
  2. No popup, abra Config em Assistente OpenRouter.
  3. Cole a chave e escolha um modelo. O padrao e ~openai/gpt-latest.
  4. Escolha se o prompt sera de Imagem, Video ou Misto.
  5. Escolha um Angulo: dor, desejo, prova, autoridade, curiosidade, antes/depois, objecao, controversia, historia emocional ou promessa.
  6. Escolha o Destino: ChatGPT, Gemini, Flow, Sora ou Veo.
  7. Escolha a Etapa da campanha e um Framework como UGC, Demo, POV, Depoimento, Reel Viral ou Gancho VSL.
  8. Escolha o Motor de skill: Angulos Criativos, Avatar Architect, Escavador de Desejos, Video Viral, Headline Forge, VSL Filemon, Mecanismo Unico ou Credibilidade.
  9. Escolha o Template de copy, como Reels UGC, POV, Objecao Destruida, Mecanismo Unico, Credibilidade ou templates especificos do JP.
  10. Descreva o objetivo, por exemplo: videos 9:16 para produto fitness, publico masculino 35+, estilo UGC.
  11. Escolha Fila por formato, Nichos e angulos, Melhorar prompt atual ou Mini campanha.

Projetos e batch diario

  1. Configure objetivo, formato, angulo, destino, etapa e framework.
  2. Preencha oferta, avatar e mecanismo para gerar roteiros mais consistentes.
  3. Use o botao JP para carregar o preset do projeto JP Freitas.
  4. Em Projeto e batch, defina nome, horario, quantidade de imagens e estilos.
  5. Use Criar fila para gerar uma fila manual imediatamente.
  6. Use Agendar para criar uma fila automaticamente todos os dias no horario definido.

Observacao: o agendamento cria a fila no armazenamento da extensao. Para executar no ChatGPT/Gemini/Flow, o Chrome precisa estar aberto, voce precisa estar logado e a aba de destino precisa aceitar a automacao.

Usar imagens baixadas

  1. No popup, use Imagens baixadas para selecionar arquivos da pasta Downloads ou de outra pasta.
  2. Clique em Criar videos das imagens selecionadas.
  3. A extensao monta uma fila de videos citando cada arquivo como first frame/referencia.
  4. No Flow, o adaptador tenta anexar a imagem no primeiro input[type=file] encontrado antes de colar o prompt.

Por seguranca do Chrome, a extensao nao le pastas automaticamente sem selecao do usuario. Se o Flow mudar o campo de upload ou esconder o input de arquivo, o upload pode precisar ser manual.

Limites do MVP

  • Os seletores dos sites podem quebrar quando ChatGPT, Gemini ou Flow mudarem a interface.
  • A captura/download de imagens e videos ainda nao esta implementada.
  • A chave do OpenRouter fica salva no armazenamento local da extensao. Para uso profissional, mova essa chamada para um backend proprio.
  • Use com intervalos razoaveis. A extensao nao tenta contornar limites dos servicos.
